# Sources of the pasted recipes

The ten texts in `pastes/` are recipes from Wikibooks, fetched on 2026-11-09 through the MediaWiki API. Wikibooks text
is under the Creative Commons Attribution-ShareAlike 4.0 licence (CC BY-SA 4.0,
https://creativecommons.org/licenses/by-sa/4.0/). The texts in `pastes/` are adapted versions under the same licence.
Authors: the contributors listed in each page's history (link below).

Changes made: wiki markup removed (links, templates, bold), the Spanish recipe box written out as plain lines, page
categories and language links removed. Four titles are redirects (Shakshouka, Lentil Soup, Beef Stew, Frittata); the table names the page the text came from, at its latest revision on the fetch date. Removed parts: "Notes, tips, and variations" sections (all English pages),
the "Equipment" list (Frittata), Variations II and III (Tuna Salad). The text is otherwise as published, typos
included, since the eval tests messy real pastes.
